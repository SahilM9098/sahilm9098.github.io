About this project

ARK Mobile Catalog & Command Helper

A lightweight fan-made reference for quickly finding ARK Mobile dinosaur paths, item blueprint paths, admin commands, and mobile-oriented graphics commands.

What the site does

The catalog is built to make command lookup faster on phones and desktop browsers. You can search by real in-game names, choose command values, and copy the generated command directly.

  • Dino catalog with searchable names and spawn command generation.
  • Item catalog with quality, quantity, and Force BP controls.
  • Admin command reference with syntax and parameter explanations.
  • Mobile-focused UE4/4.17-era graphics and performance command notes.

Accuracy and game-build differences

ARK commands and Unreal Engine console variables can behave differently between game versions, maps, devices, server settings, and mobile builds. Some commands may be ignored or may require a restart/startup configuration. Test commands carefully before relying on them in an important save.

Corrections and feedback

If you find an incorrect command, missing item, or bad blueprint path, you can report it through the public GitHub project: ark-mobile-catalog on GitHub.

This site is intended as a reference tool. Always keep backups of saves/configuration files before experimenting with commands or graphics settings.
